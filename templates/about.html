About

A web tool that uses aerial drones and machine learning to detect, classify, and map coastal marine debris.

Before you start, a few parameters matter:

  1. Drone specifications: The app is tuned for imagery from the DJI Phantom 4 Pro, using that drone's focal length and sensor width. If you use a different drone, update those values with the correct figures for your model.
  2. Image metadata: Images must carry EXIF metadata with longitude, latitude, and altitude for mapping to work.

How to use it

Each tab resets its view when you navigate to it; your results are saved automatically as you go.

  1. On Home, upload images and run detection. Review the results and adjust any classifications, then save your changes.
  2. On CSV, load the current detections, download a copy, clear them, or upload a CSV from a previous session.
  3. On Duplicates, re-upload the same images to remove debris that appears in more than one frame.
  4. On Map, view detected debris geographically. Use faster reload for large sets.
  5. On Plot, enter a number of clusters to see the distribution of debris types by area.
